# NutriPlan AI 🥗

AI-assisted personalized nutrition and meal planning application built with Streamlit and Groq.

## Features
- Personal information
- BMI screening calculation
- Health-condition input
- Blood/laboratory report upload
- Food preferences and allergies
- Number of meals
- Budget-aware planning
- AI nutrition goal recommendation
- Personalized meal plan
- Affordable alternatives
- Shopping list

## Important
This application provides educational AI-generated nutrition guidance. It does not diagnose diseases or replace a qualified doctor or registered dietitian.

## Streamlit Secrets
Add your Groq key in Streamlit Cloud:

```toml
GROQ_API_KEY = "your_groq_api_key"
```

Never commit your API key to GitHub.
